## 🚀 **What is CareerForge?**

CareerForge is a comprehensive AI-powered job search platform that helps job seekers:

- **Optimize resumes to 99% ATS match** in minutes
- **Detect red flags** in job postings to avoid toxic workplaces
- **Research companies** automatically and incorporate insights into your resume
- **Prepare for interviews** with AI-generated STAR-method answers
- **Track applications** and get follow-up suggestions

**Built with Claude AI** to give you a competitive edge in your job search.

---

## **Features**

### **Pre-Application Tools**
- **ATS Score Analysis**: See your initial score and exactly what's missing
- **Resume Optimization**: AI rewrites your resume to target 99% ATS match
- **Red Flag Detection**: Automatically identifies toxic job posting patterns
- **Company Research**: Auto-generates company insights and talking points
- **Before/After Comparison**: Shows what was fixed and why
- **Download as Word**: Export optimized resume as `.docx` for final edits

### **Post-Interview Tools**
- **STAR Interview Prep**: Generate compelling interview answers
- **Application Tracker**: Monitor all applications in one place
- **Follow-up Suggestions**: Know when and how to follow up

## **Technology Stack**

- **Frontend**: HTML5, CSS3 (Tailwind CSS), JavaScript (ES6+)
- **AI Engine**: Claude Sonnet 4 (Anthropic API)
- **Document Generation**: docx.js, FileSaver.js
- **Storage**: Browser LocalStorage (no server required)
- **Hosting**: GitHub Pages (free, fast, reliable)

## **Installation & Usage**

### **Option 1: Use Online (Recommended)**
Simply visit the [live demo](https://oluwatosin-babatunde.github.io/careerforge) - no installation needed!

### **Option 2: Run Locally**

1. **Clone the repository**
   ```bash
   git clone https://github.com/Oluwatosin-Babatunde/careerforge.git
   cd careerforge
   ```

2. **Open in browser**
   ```bash
   # Just open the HTML file
   open index.html
   # Or use a local server
   python -m http.server 8000
   ```

3. **Start optimizing resumes!**

## **Why CareerForge?**

### **The Problem**
- 75% of resumes are rejected by ATS before a human sees them
- Job seekers spend 30+ minutes tailoring each application
- Red flags in job postings often go unnoticed
- Generic resumes get lost in the pile

### **The Solution**
CareerForge automates the tedious work while maintaining quality:
- **5 minutes** per application (vs 30+ minutes manually)
- **99% ATS match** guaranteed (vs 40-70% typical scores)
- **Red flag detection** built-in (avoid toxic workplaces)
- **Company research** auto-incorporated (stand out from generic applicants)
